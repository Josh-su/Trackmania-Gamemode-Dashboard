# Trackmania Gamemode Dashboard - Plugin List

Welcome! This repository exists specifically to host the dynamic `gamemodes.json` list used by the **Gamemode Dashboard** Openplanet plugin for Trackmania.

The plugin fetches this file on startup so that new community gamemodes can be added instantly without players needing to download an update to the dashboard itself.

## How to Contribute

If you are a plugin developer or a player who found a cool new community gamemode and want it listed on the dashboard, you can request an addition by opening a new issue and providing the Openplanet link.

### Proposing Tag Changes
If you think a plugin is missing an important tag, or has incorrect tags, feel free to submit a Pull Request modifying the existing tags for that entry. 

Thanks for helping make Trackmania community game modes easier to discover!
